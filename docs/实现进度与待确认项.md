## 3. 已知偏差（事实，未隐藏）

1. 提示音为前端 Web Audio 合成，不是 Rust 侧音频播放。
2. 空闲检测：Windows 走 Win32 `GetLastInputInfo`，macOS 走 CoreGraphics `CGEventSourceSecondsSinceLastEventType`；Linux 仍返回 `None`（不误判为"已离开"）。mac 分支未经 mac 真机编译与运行验证（开发机为 Windows）。
3. 提醒弹窗的真实弹出只做过构建与启动验证，未做点击级的端到端回归（桌面自动化点击在该 WebView 上无效，已放弃该验证方式）。
4. 数据恢复走「重启后生效」：运行中的连接池仍占用当前库文件，不做热替换；待恢复文件在下次启动、建池前落位。
5. 桌面悬浮组件（`widget` / `floatWidget`）仍是占位选项：无独立置顶小窗，勾选后不会出现悬浮窗；待多窗口方案确定后实现。
6. ~~每周时间表没有做重叠时段校验~~ 已在第二轮迭代补齐：同工作日已启用时段重叠会被后端拦截。
7. `jsx-runtime-*.js`（antd/react 运行时）仍有 628 KB，属于第三方运行时体积，未再手工拆分（rolldown 的手动分块会把无关依赖拉到同一块，反而更大）。
8. 全局快捷键的真实注册/触发、改绑冲突提示、恢复默认仅通过编译与单测回归，尚未在桌面端 `tauri dev` 真机点击级验收（浏览器预览下 IPC 与热键不可用）。
9. JSON 导入是数据级写回，运行中的引擎计划快照不做热重载；导入完成后界面已刷新计划/活动/记录/设置，但计划引擎建议重启应用后再按新数据运行（与数据库恢复同口径）。
10. 历史日期范围筛选按 `started_at`（UTC ISO8601）的日期前缀比较，本地（UTC+8）跨天边界可能有几小时偏差；如需精确到本地自然日，需在后端把本地日期换算成 UTC 边界。
11. 活动配图：字段链路已打通（链接输入 + 详情预览 + 导出导入），但内置活动图片暂留空。网上可搜到的动作示意图多为 DepositPhotos / Adobe / Getty / illustAC 等商业版权图库，搜索结果里的 `aka.doubaocdn.com` 仅是代理缩略图、不可作为长期直链；未找到可免费商用且稳定直链的图源。当前仅支持填网络图片链接，本地图片文件选择与 Tauri 资源协议渲染尚未做；待有合规（CC0 / 自制 / 已授权）素材后再填充内置活动配图。
12. 「检查更新」为开发版占位提示，未接入 `tauri-plugin-updater` 或任何更新服务；正式发布打包时再实现真实更新通道。
13. 每周活动汇总按 UTC `strftime('%Y-%W')` 分组，本地（UTC+8）跨周边界可能有个别记录归到相邻周；与第 10 条同属时区口径问题。
14. 「删除所有数据」按确认不生成兜底备份、不可撤销；弹窗已提示先「导出 JSON」留存。重置后业务表清空并重新播种内置计划/活动/默认设置，引擎回退到新默认计划；与第 9 条同口径，建议完成后重启应用。
15. 图标在编译期嵌入二进制：`tauri-build` 默认只监听 `tauri.conf.json` 与 `capabilities`，不监听 `icons/`，单独替换图标后 cargo 不会重编，旧图标仍留在二进制里。已在 `build.rs` 显式 `cargo:rerun-if-changed=icons` 纳入增量监听；历史上若遇到换图标不生效，需 `cargo clean -p sithalt` 后重新编译。托盘/窗口/任务栏/安装包共用这套嵌入图标，浏览器预览看不到。
16. macOS 尚未在真机编译与打包验证（开发机为 Windows）。代码层已适配，但以下需在 mac 环境闭环：① `cargo check/build --target aarch64-apple-darwin` 验证 CoreGraphics FFI 链接；② 真机验证空闲检测、菜单栏托盘、通知、LaunchAgent 自启、全局快捷键注册触发；③ 出 `.app`/`.dmg`，Apple 签名 + 公证 + hardened runtime；④ 菜单栏模板图标需透明底单色 Z 素材（当前黑底方块不适合 `icon_as_template` 深浅自适应）；⑤ 通知/辅助功能等权限不可用时的前端引导提示；⑥ Dock 图标显隐策略（是否 Accessory 纯菜单栏模式）；⑦ 最低系统版本最终确认（现设 10.15）。

## 4. 仍需拍板的细节（PRD 第十五章）

现用默认值，改动只需调种子数据或设置项：

- 预设计划默认 30/5、45/5 还是 50/10？
- 用户连续忽略几次后是否需要自动调整节奏（间隔 / 频次）？
- 数据库备份频率与备份位置？当前默认「每 7 天一次、保留 5 份、放在数据库同级的 backups 目录」。
- 是否要做桌面浮动组件（`float_widget`）？当前 `floatWidget` 设置项存在但无对应窗口。
