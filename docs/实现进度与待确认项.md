## 3. 已知偏差（事实，未隐藏）

1. 提示音为前端 Web Audio 合成，不是 Rust 侧音频播放。
2. 空闲检测依赖 Win32 FFI，非 Windows 返回 `None`（不误判为"已离开"），macOS/Linux 待补实现。
3. 提醒弹窗的真实弹出只做过构建与启动验证，未做点击级的端到端回归（桌面自动化点击在该 WebView 上无效，已放弃该验证方式）。
4. 备份只做了「生成 + 列表 + 自动清理」，**没有做恢复入口**；恢复目前需要用户手动把备份文件替换回 `sithalt.db`（应用需先退出）。
5. 每周时间表没有做重叠时段校验：若同一星期配置了重叠时段，判定为「命中任意一段即计时」，不会报错。
6. `jsx-runtime-*.js`（antd/react 运行时）仍有 628 KB，属于第三方运行时体积，未再手工拆分（rolldown 的手动分块会把无关依赖拉到同一块，反而更大）。

## 4. 仍需拍板的细节（PRD 第十五章）

现用默认值，改动只需调种子数据或设置项：

- 预设计划默认 30/5、45/5 还是 50/10？
- 用户连续忽略几次后是否需要自动调整节奏（间隔 / 频次）？
- 数据库备份频率与备份位置？当前默认「每 7 天一次、保留 5 份、放在数据库同级的 backups 目录」。
- 是否要做桌面浮动组件（`float_widget`）？当前 `floatWidget` 设置项存在但无对应窗口。
